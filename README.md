🐍 Python Concepts Covered
This repository includes various Python files that demonstrate fundamental to intermediate concepts in Python programming. Each file is focused on a specific topic or concept. Below is a categorized summary of what’s covered:

📌 Basics
variables.py – Declaring variables, naming rules, and data types.

string.py – String manipulation, methods, indexing, slicing, and formatting.

statements.py – Syntax and structure of Python statements.

🔄 Control Flow
if-else, switch & ternary:

switchStatement.py – Using match-case (Python’s switch-like construct).

ternaryOperator.py – One-line conditional expressions.

Loops:

forLoop.py – Using for loops with ranges, lists, and dictionaries.

whileLoop.py – Iteration with while and condition tracking.

NestedLoop.py – Loops inside loops for 2D data and patterns.

🧮 Operators & Expressions
membershipOp.py – Demonstrating in and not in operators.

listComprehensive.py – Powerful one-liners with list comprehensions.

🧰 Functions & Decorators
Functions.py – Defining and using functions, *args, **kwargs.

decorators.py – Function decorators, use cases, and chaining.

📦 Collections & Iterables
Collection.py – Lists, tuples, sets, and dictionaries with examples.

iterables.py – Iterators vs iterables, custom iteration.

🎲 Random & Math
RandomNo.py – Generating random numbers and using random module.

math_fun.py – Using Python’s math module for mathematical operations.

🕰️ Date & Time
dateTime.py – Working with dates, times, and timestamps.

💡 OOP (Object-Oriented Programming)
OOP.py – Classes, objects, attributes, and methods.

classVarOOP.py – Class variables and instance variables.

Inheritance.py – Inheritance and method overriding.

super().py – Using super() to access parent class methods.

polymorphisim.py – Polymorphism in action with multiple object types.

duckTyping.py – Understanding duck typing in Python.

📄 File & Exception Handling
fileDetection.py – File I/O operations: reading, writing, and detecting.

exceptionHandling.py – Try-except blocks, raising errors, custom exceptions.

🧵 Multithreading
multiThreading.py – Running multiple threads for concurrent tasks.

🌐 APIs & Web
requestsApi.py – Making HTTP requests using the requests library.

🧪 Miscellaneous
main1.py and main2.py – Combining logic, testing functions, and integration.

methods.py – Built-in methods for various data types.

switchStatement.py – Modern pattern matching in Python 3.10+
